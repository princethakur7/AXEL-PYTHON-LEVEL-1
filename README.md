## 📖 About This Repository

Welcome to the **AXEL PYTHON LEVEL-1** repository.

This repository contains all source codes, practice programs, assignments, and projects completed during the Python Level-1 training program.

The goal of this course is to build a strong foundation in Python programming through hands-on coding and real-world projects.

Students will learn:

- Python Fundamentals
- Variables & Data Types
- Conditional Statements
- Loops
- Functions
- Lists & Collections
- Problem Solving
- Logic Building
- Project Development

---

## 🚀 Projects Included

### ✅ To-Do List Application
A simple task management program that allows users to add, view, and remove tasks.

**Concepts Used**
- Lists
- Loops
- Functions
- Menu Driven Programming

---

### 🔐 Password Generator
A random password generator that creates secure passwords based on user requirements.

**Concepts Used**
- Random Module
- Strings
- Functions
- User Input Handling

---

### 🎯 Hangman Game
A classic word guessing game where the player must guess the hidden word before running out of attempts.

**Concepts Used**
- Loops
- Functions
- String Manipulation
- Conditional Statements

---

### ✂️ Rock Paper Scissors
A fun game where the user competes against the computer.

**Concepts Used**
- Random Module
- Conditions
- Functions
- Game Logic

---

### 🏦 Bank Management System
A menu-driven banking project that simulates basic banking operations.

**Features**
- Deposit Money
- Withdraw Money
- Check Balance
- Transaction Validation

**Concepts Used**
- Functions
- Loops
- Conditional Statements
- Menu Driven Programming
